# 🎬 CineMate — Movie Recommendation & Ticket Booking

CineMate is a full-stack movie discovery and ticket-booking web app built with **Streamlit**. It combines a content-based ML recommender with a complete theatre booking flow (city → theatre → showtime → seat map → payment), an AI movie assistant powered by Google Gemini, watchlists, ratings, and an admin dashboard — all in a single Python codebase.

## Features

- **Movie discovery** — trending, now playing, Bollywood/Hollywood/South Indian filters, search by title/actor/genre, and mood-based picks
- **ML-powered recommendations** — TF-IDF + cosine similarity "because you watched" suggestions, plus a hybrid recommender that blends mood, genre history, and popularity
- **Ticket booking** — city → theatre → showtime → interactive seat map (with short-lived seat locks to avoid double-booking) → mock payment → downloadable ticket with QR code
- **AI Movie Assistant** — a Gemini-powered chat assistant that recommends movies conversationally
- **Accounts** — signup/login with salted PBKDF2 password hashing, profile photos, booking history, and password changes
- **Watchlist & ratings** — save movies for later and rate what you've watched
- **Admin dashboard** — manage movies, theatres/showtimes, bookings, and users, with an at-a-glance KPI overview

## Tech stack

| Layer | Technology |
|---|---|
| UI / app framework | [Streamlit](https://streamlit.io) |
| Recommendation engine | scikit-learn (TF-IDF + cosine similarity) |
| Data | pandas, [TMDB](https://www.themoviedb.org/) API |
| Storage | SQLite |
| AI chat | Google Gemini (`google-generativeai`) |
| Email | smtplib (booking confirmations) |

## Getting started

### 1. Clone and install dependencies

```bash
git clone https://github.com/YashWagh23/Movie-recommendation-and-Ticket-booking.git
cd Movie-recommendation-and-Ticket-booking
pip install -r requirements.txt
```

### 2. Configure environment variables

Copy `.env.example` to `.env` and fill in your own keys:

```bash
cp .env.example .env
```

| Variable | Required | Purpose |
|---|---|---|
| `TMDB_API_KEY` | Recommended | Posters, trailers, cast, reviews, and live "now playing"/trending data. Free key at [themoviedb.org](https://www.themoviedb.org/settings/api). Without it the app still runs, with placeholder posters and no live movie data. |
| `GEMINI_API_KEY` | Optional | Powers the AI Assistant chat tab. Free key at [aistudio.google.com](https://aistudio.google.com/app/apikey). |
| `SMTP_HOST` / `SMTP_PORT` / `SMTP_USER` / `SMTP_PASS` / `SMTP_FROM` / `SMTP_TLS` | Optional | Emails booking confirmations after a successful payment. |
| `OPENAI_API_KEY` | Optional | Alternate chat backend used by a fallback formatter. |

> **Never commit your real `.env` file.** It's already covered by `.gitignore`.

### 3. Generate the recommendation model

The trained model files (`movies.pkl`, `similarity.pkl`) are derived data and aren't committed to the repo — generate them locally:

```bash
python model.py
```

This reads `tmdb_5000_movies.csv` (included in the repo) and builds a TF-IDF similarity matrix. It only needs to be run once, or whenever you want to rebuild the model.

### 4. Run the app

```bash
streamlit run app.py
```

The app opens at `http://localhost:8501`.

## Project structure

```
app.py              # entry point: session state, sidebar, tab routing
auth.py              # login / signup
home.py              # discovery, search, recommendations, ratings
booking.py           # city/theatre/showtime/seat selection + mock payment
ai_assistant.py       # Gemini-powered chat assistant
watchlist.py         # saved movies
profile.py           # account details, password change, booking history
admin.py             # admin dashboard (movies, theatres, bookings, users)
utils.py             # shared styling, DB access, TMDB client, recommender
model.py             # builds movies.pkl + similarity.pkl from the TMDB CSV
model_upgrade.py     # optional: builds a larger model from a bigger dataset
```

## Notes on data

- `app.db` (SQLite) is created automatically on first run and is gitignored.
- `movies.pkl` / `similarity.pkl` are generated by `model.py` (see step 3 above) and are gitignored — they're derived from `tmdb_5000_movies.csv`, which is included.
- `model_upgrade.py` is an optional script for building a larger, multi-language model from a bigger TMDB export (`TMDB_all_movies.csv`, not included) — most users only need `model.py`.
